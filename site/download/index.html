Downloading FM Lens

Your download starts in a moment. If it does not, download it from GitHub.

On a Mac, open the disk image and drag FM Lens onto Applications. The first time, macOS cannot check the app: open System Settings › Privacy & Security and choose Open Anyway.

On Windows, run the installer. If Windows protected your PC, choose More info, then Run anyway.
