## What's new

FM Lens 0.6.2 is here for Windows. Download the installer from getfmlens.com, connect to FM27 on Steam and search, compare and edit your career on your PC, with updates that install themselves from now on.

### FM Lens for Windows

- Download FM Lens for Windows from getfmlens.com/download. The installer sets it up for your Windows account, with no administrator password, and adds it to the Start menu.
- It works with FM27 from Steam, version 27.0.0 (build 26340721), on 64-bit Windows 10 and 11. Other builds open read-only.
- No setup step on Windows: start FM from Steam, load a copy of your save and choose Connect.
- Edit your career as on a Mac. In our tests on Windows, attributes and CA/PA, contracts, mass edits, clone and templates, frozen money, Heal, Refresh fitness, Max morale, Max cohesion and your manager all applied and undid cleanly.
- The game's own actions run inside FM on Windows too: add and heal injuries, grant work permits, start and end loans, sign free agents, transfers and future transfers, manager moves and max tactics.
- Windows SmartScreen may stop the first run, as FM Lens is new and not signed by a big publisher. Choose More info, then Run anyway.

### Updates on Windows

- FM Lens for Windows keeps itself up to date. When a new version is out, it downloads in the background while you keep working.
- Press Relaunch to update, at the foot of the window, when it suits you: FM Lens installs the new version and opens it again in seconds.
- Want the latest right away? Check for Updates is in Settings, About.

### Made for Windows

- If Windows Security blocks an export, FM Lens tells you how to allow it under Controlled folder access, instead of showing an error code.
- Report a problem fills in your Windows edition and version, so we can help faster.
- Player promises are not available on Windows yet. The profile says so, instead of showing none.

### Website

- getfmlens.com has a privacy page that lists exactly what FM Lens and the site send, and how to turn it off.
- Links to the download, release notes and privacy pages now show a preview card when you share them.
- Search engines can find every page, and the site icon shows in more browsers.

### On Mac and Windows

- One FM Lens at a time: open it again, from the Dock, the Start menu or a second copy, and the window you already have comes to the front. Two copies can no longer edit the same career at once.
- Tell your friends on PC: FM Lens is on Windows now.
