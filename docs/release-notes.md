## What's new

FM Lens 0.7.2 is a fix for Windows. On some PCs every transfer, swap and loan stopped with "LoadLibraryW failed: Win32 error 126". That error is gone, and you do not have to install anything to be rid of it.

### Windows: transfers, swaps and loans

- Transfer, Swap and Loan now work on PCs that do not have Microsoft's Visual C++ runtime installed. Before, they failed there with "LoadLibraryW failed: Win32 error 126", while the rest of FM Lens worked.
- The same goes for every other action FM Lens has FM carry out itself, such as Release.
- If you installed Microsoft's Visual C++ Redistributable to get round the error, you can keep it or remove it. FM Lens no longer needs it.

### Mac

- Nothing changes on a Mac. The update keeps Mac and Windows on the same version.

### Downloads and reports

- The download page on getfmlens.com always has a download for you, even when GitHub is too busy to say which version is the latest.
- FM Lens now takes up to 1,000 reports a day, so yours is less likely to be turned away on a busy day.
