## What's new

FM Lens 1.1.4 brings editing to the newest Game Pass version of Football Manager 27, and gets you back to editing sooner the next time FM updates. Everything below is new since 1.1.3.

### Game Pass 0.9.2524.0: editing is on

- Game Pass moved FM27 to version 0.9.2524.0 on 17 November, the update Steam calls 27.1.0. Since then FM Lens could only read a Game Pass career. FM Lens 1.1.4 knows this version, so editing is on again.
- That covers the edits FM Lens makes itself: attributes, CA and PA, contracts, club money, staff and nations. Undo in Changes puts any of them back.
- As on earlier Game Pass versions, the moves FM makes for FM Lens, such as transfers, loans and healing injuries, are for Steam.
- We do not own a Game Pass copy, so this version has not been played through by us the way Steam versions are. Edit a copy of your save, and tell us from Report a problem if anything looks wrong.

### Back to editing sooner after an FM update

- When FM updates to a version FM Lens does not know yet, FM Lens opens your career read-only. From 1.1.4 it then looks for its own update every 30 minutes while it stays open, so the fix reaches you without restarting the app. Press Relaunch when it appears.
- The read-only notice now tells you what happens next: if you gave your email, we email you when your version works.

### What FM Lens counts

- To support new game versions faster, FM Lens now counts a few more things, with no name, no save and nothing about your career: that a career opened read-only and on which game version, which version of the game's files it found, whether its own checks passed there, and that an update was offered or installed. The download page counts which link brought a visitor, when the link says so.
- The full list is in the README and on getfmlens.com/privacy. Settings turns all of it off.

### Updating

- Open FM Lens and it fetches 1.1.4 by itself. Press Relaunch to update when it appears, or download 1.1.4 from getfmlens.com.
- Steam versions keep working: 27.1.0, 27.0.1 and 27.0.0, and so does Game Pass version 0.9.2435.0.
- As always, edit a copy of your save.

FM Lens is free and open source, and it will stay that way. A [star on GitHub](https://github.com/IamDejman/fm-lens) encourages me.
