## What's new

- On Intel Macs, every successful Apply and Undo now asks FM to refresh the edited record and its active screens without pressing Continue. Other fields and panels have not all been checked.
- FM Lens updates keep using the helper already running in FM. Supported features keep working without restarting the game.

An older helper may not refresh FM's screens immediately or support a newly added action. The latest helper loads the next time you start FM.
